Part 2

How drift detection works today

What the current backend and dashboard do, traced through the code. We ran the engine on the demo workspace to get the numbers below.

1 · Input

Workspace

docs/*.md (PRDs, architecture specs) and services/*/*.py. Path set by STAVVROS_WORKSPACE_PATH.

2 · Parse

Two parsers

  • code_parser.py reads the Python AST: route decorators, status codes, Kafka topics, outgoing calls. Output: CodeEndpoint.
  • markdown_parser.py reads FleetHD sections and API lines. Sync or async is guessed from nearby words. Output: DocContract.
3 · Compare

Drift rules

  • 001 Version: doc path missing, a similar route exists
  • 002 Protocol: same path, doc sync, code async
  • 003 Phantom: doc route with no code
  • 004 Undocumented: code route with no doc
  • LLM evaluator: stub, not active
4 · Graph

Knowledge graph

NetworkX graph of teams, services, APIs and docs. A drift_flagged edge links the doc to the API.

5 · Serve

FastAPI

  • GET /api/graph: nodes, edges, alerts, KPIs
  • GET /api/nodes/{id}: alerts for one node
  • POST /api/drift/reconcile/{id}
6 · Show

Dashboard

  • KPI tile: active drift count
  • Red dashed edge on the graph
  • Node Inspector “Drift Diff” tab, doc line vs code line
  • One-click Reconcile

Engine issues found while building the demo

  1. Doc line numbers are one too low. markdown_parser.py stores a 0-based index, so alerts say line 55 for line 56.
  2. Nodes never show drift. graph_builder.py writes status beside the node data instead of inside it, so every node comes back active and the red node borders never appear.
  3. Only the refund drift gets a graph edge. Drift edges need the contract's domain tag in the code path; the transactions route is tagged order, so its alerts are invisible on the graph.
  4. Renamed path parameters cause three alerts. Normalising {id} and {transaction_id} before comparing would remove three of the five alerts above.
  5. Reconcile does not stick. The next re-scan rebuilds alerts from scratch, so a reconciled drift comes back unless the doc changed.
